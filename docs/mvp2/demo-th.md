# MVP2: ขั้นตอนทดสอบและสคริปต์เดโม (พร้อมใช้งานจริง)

ทำต่อจาก [MVP1](../mvp1/demo-th.md) ได้เลย ใช้เวลาประมาณ 25 นาที ทำตามลำดับ 1 → 11

## เตรียมข้อมูล

| ที่ไหน | ทำอย่างไร | ได้อะไรเพิ่มจาก MVP1 |
|---|---|---|
| เครื่อง local | `pnpm db:reset` แล้ว `pnpm dev` | ใบสมัคร **กล้า** นัดทดลองเรียนคลาสถัดไป · ครูสมชายเป็นครูประจำทุกคลาส · งาน `registerweb-nightly` ใน pg_cron |
| Cloud | รัน `packages/db/supabase/demo/cloud_demo.sql` อีกครั้ง (รันซ้ำได้) | ใบสมัคร **กล้า** นัดทดลองเรียน · ครูเป็นครูประจำทุกคลาสตั้งแต่วันนี้ |

ผู้ใช้: admin, ผู้จัดการ (local: `manager@demo.test`), ครู, ผู้ปกครอง, kiosk · รหัสผ่าน local อยู่หัวไฟล์ seed
ต้องมีเครื่องสแกนบาร์โค้ดหรือมือถืออีกเครื่องสำหรับเปิดบัตรนักเรียน (ข้อ 8)

## ขั้นตอน

| # | ใคร | ทำอะไร | ต้องเห็น |
|---|---|---|---|
| 1 | ครู | **ใบสมัคร** → เปิดใบสมัครใหม่ (หรือของ ใบเตย) → **นัดทดลองเรียน** เลือกคลาสถัดไป | ใบสมัครขึ้น "นัดทดลองเรียน" พร้อมวัน เวลา คลาส |
| 2 | ผู้ปกครอง | ข้อมูลนักเรียน → ใบสมัครของฉัน | เห็นวันและเวลาทดลองเรียน |
| 3 | ครู | **ทดลองเรียน** → เปิด กล้า → มาเรียน: ใช่ · ให้คะแนน 4 ด้าน · บันทึก · แนะนำแพ็กเกจ 8 ครั้ง → บันทึก → **อนุมัติเป็นนักเรียน** | ได้รหัส S0000x · ไปหน้านักเรียนแล้วกดขายแพ็กเกจ เห็นแพ็กเกจที่แนะนำถูกเลือกไว้ |
| 4 | ผู้จัดการ | **คลาสและเช็คชื่อ** → เปิดคลาสวันนี้ → **ครูประจำคลาส** เลือกครู เปิด "ใช้กับคลาสนี้ทุกสัปดาห์" → บันทึก | รายชื่อครูขึ้นที่คลาส และที่คลาสเดียวกันสัปดาห์หน้า |
| 5 | ครู (ครูประจำคลาส) | คลาสวันนี้ → นักเรียนที่จองไว้ → **เช็คชื่อแทน** เลือก "ลืมบัตร" → ยืนยัน | ขึ้นครั้งที่เหลือ · รายชื่อขึ้น "ครูเช็คชื่อแทน · ลืมบัตร" พร้อมชื่อครู · ครูที่ไม่ใช่ครูประจำคลาสไม่มีปุ่มนี้ |
| 6 | admin | คลาสเดียวกัน → การเช็คชื่อข้อ 5 → **ยกเลิกการเช็คชื่อ** ใส่เหตุผล "เช็คชื่อผิดคน" | รายการถูกขีดฆ่าพร้อมเหตุผล · ครั้งที่เหลือกลับคืน 1 ครั้ง · การจองกลับเป็น "จองแล้ว" · เช็คชื่อใหม่ได้ |
| 7 | ผู้จัดการ | **นักเรียน** → เปิดนักเรียน → ขายแพ็กเกจเงินสด → เปิดใบเสร็จ → **ขอยกเลิกใบเสร็จ** เหตุผล "คิดเงินผิดแพ็กเกจ" | ใบเสร็จขึ้น "รอแอดมินอนุมัติยกเลิก" |
| 7.1 | admin | **คิวตรวจ** → คำขอข้อ 7 → **อนุมัติ** | ใบเสร็จขึ้นตรา "ยกเลิกแล้ว" (ทั้งบนจอและตอนพิมพ์) · แพ็กเกจจากใบเสร็จนี้หายจากรายการที่ใช้ได้ |
| 7.2 | admin | ขอยกเลิกใบเสร็จของนักเรียนที่เช็คชื่อไปแล้ว → อนุมัติ | ขึ้น "แพ็กเกจจากใบเสร็จนี้มีการเช็คชื่อแล้ว ให้ยกเลิกการเช็คชื่อก่อน" · ลองกด **ไม่อนุมัติ** พร้อมเหตุผล → ใบเสร็จกลับเป็นปกติ |
| 8 | ผู้ปกครอง | ข้อมูลนักเรียน → **บัตรนักเรียน** → พิมพ์ (หรือเปิดค้างบนมือถือ) | บัตรขนาดบัตรเครดิต มีรูป ชื่อ สาย บาร์โค้ด และ QR |
| 8.1 | kiosk | เลือกคลาสวันนี้ → สแกนบาร์โค้ดบนบัตร แล้วลองสแกน QR | เช็คชื่อสำเร็จ (ครั้งที่ 2 ขึ้นว่าเช็คชื่อแล้ว) |
| 9 | admin | **ประวัติการแก้ไข** → เลือกช่วงวันนี้ | เห็นทุกขั้นตอนข้างบน: นัดทดลองเรียน, บันทึกผลทดลอง, อนุมัติ, ตั้งครูประจำคลาส, เช็คชื่อ (manual), ยกเลิกเช็คชื่อ, ขอ/อนุมัติ/ไม่อนุมัติยกเลิกใบเสร็จ พร้อมผู้ทำและเหตุผล · กรองตามประเภทได้ |
| 10 | admin | **นำเข้านักเรียน** → ดาวน์โหลดไฟล์ตัวอย่าง → ใส่ 3 แถว (1 แถวผิด: วันเกิด 31/02/2560) → บันทึกเป็น CSV UTF-8 → อัปโหลด | ตารางตรวจสอบขึ้นแถวที่ผิดพร้อมช่องและเหตุผล ปุ่มนำเข้ากดไม่ได้ → แก้แล้วอัปโหลดใหม่ → **นำเข้า 3 คน** → นักเรียนใหม่อยู่ในรายชื่อ (รหัสเดิมจากไฟล์ หรือรหัส S ใหม่) |
| 10.1 | ครู | เปิดนักเรียนที่นำเข้า → **เชื่อมบัญชีผู้ปกครอง** ใส่อีเมลผู้ปกครอง | ผู้ปกครองเห็นนักเรียนคนนี้ในหน้าข้อมูลนักเรียน · อีเมลที่ไม่เคยเข้าสู่ระบบขึ้นว่าไม่พบบัญชี |
| 11 | admin (cloud) | Supabase → SQL: `select jobname, schedule from cron.job` | `registerweb-nightly` `30 17 * * *` (00:30 น. เวลาไทย) |

## เช็กก่อนส่งงาน

- `DATABASE_URL="postgresql:///postgres?host=/tmp" pnpm db:test` ผ่านทุกข้อ
- `pnpm --filter @registerweb/web typecheck`, `lint`, `build` ผ่าน
- ขั้นตอน 1–11 ผ่านบนคอม iPad และมือถือ ไม่มี error ใน console
- ทุกข้อความบนหน้าจอเป็นภาษาไทย
