# เช็กลิสต์ก่อนเปิดใช้งานจริง (ทดสอบด้วยข้อมูลจริง)

ทำบน Supabase + Cloudflare ของจริง ทีละข้อ ติ๊กเมื่อผ่าน ข้อที่ไม่ผ่านให้จดไว้และแก้ก่อนเปิดใช้ · วิธีตั้งค่าและ deploy อยู่ใน [คู่มือขึ้นระบบ](../deploy-th.md)

## A. ระบบ (admin / ผู้พัฒนา)

- [ ] ขึ้น prod ด้วย tag `v*` และงาน **Security** ผ่านทุกข้อ (ห้ามข้าม) · migration ล่าสุดขึ้นแล้ว (`supabase db push --linked --dry-run` ไม่มีรายการค้าง)
- [ ] โปรเจกต์ prod ถูกตัว: `SUPABASE_PROJECT_REF` ของ environment production ตรงกับโปรเจกต์ของโรงเรียน (ไม่ใช่ staging)
- [ ] `select jobname, schedule from cron.job` มี `registerweb-nightly` `30 17 * * *`
- [ ] GitHub environment production: ไม่มีตัวแปร `NEXT_PUBLIC_DEV_LOGIN` · Google sign-in ใช้ได้ที่ `app.<โดเมน>`
- [ ] **ไม่ได้รัน `seed.sql` บน cloud** (มีผู้ใช้ `@demo.test` = ต้องลบโปรเจกต์ทดสอบนั้นทิ้ง)
- [ ] สำรองข้อมูล: งาน **Prod DB backup** ผ่าน และมีไฟล์ใน R2 `registerweb-backups` · ทดสอบกู้บน staging แล้ว · โรงเรียนเก็บ `BACKUP_PASSPHRASE` ไว้
- [ ] งาน **Prod health check** ผ่าน · สลิปทดสอบเปิดได้เฉพาะผู้ปกครองเจ้าของและครูสาขาเดียวกัน
- [ ] PDPA: เซ็น DPA ของ Supabase และ Cloudflare แล้ว · หน้า `/privacy` และข้อความยินยอมระบุว่าเก็บข้อมูลที่สิงคโปร์ (ทนายตรวจแล้ว)
- [ ] ตรวจสิทธิ์เข้าถึงตามการ์ด #73 (ทุก role และสมาชิกบัญชี Cloudflare / Supabase / GitHub / Google)

## B. ตั้งค่าโรงเรียน (admin)

- [ ] สาขาทุกสาขา: ชื่อ รหัส ที่อยู่ · VAT ตามที่ใช้จริง
- [ ] พร้อมเพย์และบัญชีธนาคาร **ของโรงเรียนเอง** (โอนทดสอบ 1 บาทเข้าบัญชีจริงแล้วตรวจชื่อบัญชี)
- [ ] ตารางเรียนประจำสัปดาห์ครบ → สร้างคลาส 4 สัปดาห์
- [ ] แพ็กเกจและราคา · ค่าสมาชิกรายปี
- [ ] ผู้ใช้: ครูและผู้จัดการทุกคนตั้ง role + สาขาแล้ว · เครื่อง kiosk ทุกสาขา
- [ ] ครูประจำคลาสครบทุกคลาส (ทุกสัปดาห์)

## C. ข้อมูลนักเรียนเดิม

- [ ] กรอกไฟล์ตัวอย่างครบ: ชื่อไทย/อังกฤษ วันเกิด สาย วันหมดสมาชิก ผู้ปกครอง เบอร์
- [ ] นำเข้าทีละสาขา · ตรวจตารางข้อผิดพลาดจนเป็น 0 · นำเข้า
- [ ] สุ่มตรวจ 10 คน: ชื่อ สาย วันหมดสมาชิก รหัสบัตร ตรงกับข้อมูลเดิม
- [ ] นักเรียนที่ยังมีครั้งเรียนเหลือจากระบบเดิม: ขายแพ็กเกจให้ตรงจำนวนที่เหลือ (บันทึกวิธีจ่ายตามจริง)
- [ ] เชื่อมบัญชีผู้ปกครอง (ผู้ปกครองเข้าสู่ระบบ 1 ครั้งก่อน)

## D. ทดลองใช้จริง 1 วันต่อสาขา

- [ ] iPad + เครื่องสแกนตาม [คู่มือตั้งค่า](ipad-scanner-th.md) · สแกนบัตรพิมพ์จริงและบัตรบนจอมือถือได้
- [ ] พิมพ์บัตรนักเรียนชุดแรก ขนาดถูกต้อง สแกนติดทุกใบ
- [ ] เช็คชื่อทั้งคลาส · ลืมบัตร 1 คน (เช็คชื่อแทน) · ยกเลิก 1 รายการ (admin)
- [ ] ผู้ปกครอง 3 คนเข้าระบบ เห็นครั้งเหลือถูกต้อง · ซื้อแพ็กเกจด้วยสลิป 1 รายการ · ครูตรวจรับเงิน
- [ ] ทดลองเรียน 1 คน: นัด → ประเมิน → อนุมัติ → ขาย
- [ ] วันถัดไป: การจองที่ไม่มาเรียนเปลี่ยนเป็น "ขาด" (งาน 00:30 น. ทำงาน)
- [ ] admin เปิดประวัติการแก้ไข เห็นทุกรายการของวันทดลอง

## E. อบรมและเปิดใช้

- [ ] อบรมครูตาม [คู่มือครู](teacher-guide-th.md) ครบทุกคน
- [ ] แจ้งผู้ปกครอง: ลิงก์เว็บ วิธีเข้าสู่ระบบ วิธีดูบัตรนักเรียน
- [ ] กำหนดผู้ติดต่อเมื่อระบบมีปัญหา และวิธีเช็คชื่อสำรอง (จดชื่อแล้วเช็คชื่อแทนภายหลัง)
