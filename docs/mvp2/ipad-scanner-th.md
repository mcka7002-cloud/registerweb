# ตั้งค่า iPad และเครื่องสแกนบาร์โค้ดสำหรับเช็คชื่อ

ใช้กับหน้า **เช็คชื่อ (kiosk)** ที่หน้าห้องเรียน ต้องต่ออินเทอร์เน็ตตลอดเวลา (MVP2 ยังไม่มีโหมดออฟไลน์)

## สิ่งที่ต้องมี

- iPad (iPadOS 16 ขึ้นไป) + ขาตั้ง + สายชาร์จที่เสียบค้างได้
- เครื่องสแกนบาร์โค้ด Bluetooth ที่อ่าน **Code 128** และ **QR** ได้ และทำงานแบบ "คีย์บอร์ด" (HID)
- บัญชี Google สำหรับเครื่องนี้โดยเฉพาะ (เช่น kiosk ของสาขา) ที่ admin ตั้ง role เป็น **เครื่องเช็คชื่อ** และผูกสาขาแล้ว

## 1. ตั้งค่า iPad

1. ตั้งค่า → จอภาพและความสว่าง → ล็อกอัตโนมัติ → **ไม่ใช้**
2. ตั้งค่า → การชาร์จ/แบตเตอรี่: เสียบสายชาร์จค้างไว้
3. ตั้งค่า → ทั่วไป → แป้นพิมพ์: ปิด "แก้ไขอัตโนมัติ" และ "ตัวพิมพ์ใหญ่อัตโนมัติ"
4. เปิด Safari → เข้าเว็บของโรงเรียน → ล็อกอินด้วยบัญชี kiosk
5. ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม** แล้วเปิดจากไอคอนนั้น (เต็มจอ ไม่มีแถบที่อยู่)
6. (แนะนำ) ตั้งค่า → การช่วยการเข้าถึง → **การเข้าถึงที่บังคับ** (Guided Access) เปิดไว้ แล้วกดปุ่มด้านข้าง 3 ครั้งในแอป เพื่อล็อกไม่ให้ออกจากหน้าเช็คชื่อ

## 2. จับคู่เครื่องสแกน

1. เปิดเครื่องสแกน ตั้งเป็นโหมด Bluetooth HID ตามคู่มือของรุ่น (ส่วนใหญ่สแกนบาร์โค้ดตั้งค่าในคู่มือ)
2. ตั้งให้ส่ง **Enter** ต่อท้ายทุกครั้งที่สแกน (suffix = CR/Enter)
3. ตั้งภาษาแป้นพิมพ์ของเครื่องสแกนเป็น **US** และตั้ง iPad ให้ใช้แป้นพิมพ์ฮาร์ดแวร์ภาษาอังกฤษ (ถ้าเป็นภาษาไทย รหัสจะเพี้ยน)
4. iPad: ตั้งค่า → Bluetooth → เลือกชื่อเครื่องสแกน
5. เมื่อจับคู่แล้วแป้นพิมพ์บนจอจะหายไป ถ้าต้องพิมพ์เองให้ปิด Bluetooth ชั่วคราว

## 3. ทดสอบก่อนเปิดคลาส

1. เปิดหน้าเช็คชื่อ → เลือกคลาสวันนี้
2. สแกนบัตรนักเรียนตัวอย่าง (บาร์โค้ด แล้วลอง QR) → ต้องขึ้นชื่อและคลาส
3. สแกนใบเดิมซ้ำ → ต้องขึ้น "เช็คชื่อคลาสนี้แล้ว"
4. ถ้าสแกนแล้วไม่มีอะไรเกิดขึ้น: แตะช่องกรอกรหัสหนึ่งครั้ง แล้วสแกนใหม่

## ปัญหาที่พบบ่อย

| อาการ | แก้ |
|---|---|
| รหัสที่ขึ้นเป็นภาษาไทยหรือตัวอักษรแปลก | เปลี่ยนแป้นพิมพ์ฮาร์ดแวร์ของ iPad เป็นภาษาอังกฤษ (US) |
| สแกนแล้วต้องกด Enter เอง | ตั้ง suffix Enter ที่เครื่องสแกน |
| อ่านบาร์โค้ดจากจอมือถือไม่ได้ | เพิ่มความสว่างจอ หรือใช้ QR แทน (เครื่องสแกนแบบ 2D) |
| ขึ้น "ไม่ได้จองคลาสนี้" | ครูจองคลาสให้ก่อน หรือใช้ **เช็คชื่อแทน** ในหน้าคลาส |
| ขึ้น "ครั้งคงเหลือ = 0" หรือ "แพ็กเกจหมดอายุ" | ให้ผู้ปกครองซื้อแพ็กเกจใหม่ แล้วจองคลาส |
| อินเทอร์เน็ตหลุด | เช็คชื่อไม่ได้จนกว่าจะต่อใหม่ ครูจดชื่อไว้แล้วใช้ **เช็คชื่อแทน** ภายหลังในวันเดียวกัน |
