# คู่มือครู (ฉบับอบรมก่อนใช้งานจริง)

ใช้อบรมครูและผู้จัดการสาขา ประมาณ 45 นาที ให้ครูลองทำเองทุกข้อบนเครื่องจริง (ระบบทดสอบ)

## เข้าใช้งาน

- เข้าเว็บโรงเรียน → **เข้าสู่ระบบด้วย Google** ด้วยอีเมลที่แจ้ง admin ไว้
- ครั้งแรกจะยังไม่มีเมนูครู ให้ admin ตั้งสิทธิ์ (ผู้ใช้ → ครู + สาขา) แล้วรีเฟรช

## งานประจำวัน

| เวลา | ทำอะไร | เมนู |
|---|---|---|
| ก่อนคลาส | ดูคลาสวันนี้ รายชื่อที่จอง และคนที่มาทดลองเรียน | หน้าครู · คลาสและเช็คชื่อ · ทดลองเรียน |
| ก่อนคลาส | เปิด iPad หน้าเช็คชื่อ เลือกคลาสวันนี้ | เช็คชื่อ |
| ระหว่างคลาส | นักเรียนสแกนบัตรเอง · ใครลืมบัตร ครูกด **เช็คชื่อแทน** และเลือกเหตุผล | คลาสและเช็คชื่อ → คลาส |
| คนมาทดลองเรียน | บันทึกว่ามาเรียน ให้คะแนน 4 ด้าน เขียนหมายเหตุ แนะนำแพ็กเกจ | ทดลองเรียน |
| หลังคลาส | อนุมัติใบสมัครที่ทดลองเรียนผ่าน · ขายแพ็กเกจ · จองคลาสถัดไป | ใบสมัคร · นักเรียน |
| เมื่อผู้ปกครองโอนเงิน | ดูสลิป ยืนยันรับเงิน หรือปฏิเสธพร้อมเหตุผล | ตรวจการชำระเงิน |

## กฎที่ควรรู้

- **เช็คชื่อแทน** ทำได้เฉพาะครูประจำคลาสนั้น (ถ้าคลาสยังไม่มีครูประจำ ครูของสาขาทำได้) และต้องใส่เหตุผลทุกครั้ง
- นักเรียนต้องถูก **จองคลาส** ก่อนจึงเช็คชื่อได้ จองจากหน้านักเรียน → จองคลาส
- เช็คชื่อผิดคนหรือผิดคลาส: แจ้ง **admin** ให้ยกเลิก (ครูยกเลิกเองไม่ได้) แล้วเช็คชื่อคนที่ถูกใหม่
- ใบเสร็จออกผิด: เปิดใบเสร็จ → **ขอยกเลิกใบเสร็จ** ใส่เหตุผล → รอ admin อนุมัติในคิวตรวจ ห้ามออกใบใหม่ซ้ำก่อนได้รับอนุมัติ
- ทุกการแก้ไขถูกบันทึกในประวัติการแก้ไข พร้อมชื่อผู้ทำและเหตุผล

## ผู้จัดการสาขาเพิ่มเติม

- ตั้ง **ครูประจำคลาส**: คลาสและเช็คชื่อ → คลาส → ครูประจำคลาส (เลือก "ทุกสัปดาห์" เพื่อใช้กับคลาสเดียวกันทุกสัปดาห์)
- **นำเข้านักเรียนเดิม** จากไฟล์ Excel/CSV: นำเข้านักเรียน (ดูไฟล์ตัวอย่างในหน้านั้น)
- **เชื่อมบัญชีผู้ปกครอง** กับนักเรียนที่นำเข้า: หน้านักเรียน → เชื่อมบัญชีผู้ปกครอง (ผู้ปกครองต้องเข้าสู่ระบบด้วย Google 1 ครั้งก่อน)

## แบบฝึกหัดอบรม (ทำบนระบบทดสอบ)

1. นัดทดลองเรียนให้ใบสมัครหนึ่ง แล้วบันทึกผลประเมิน และอนุมัติ
2. ขายแพ็กเกจ 8 ครั้งเงินสด แล้วจองคลาส 2 วัน
3. เปิด iPad สแกนบัตร แล้วลองเช็คชื่อแทนอีกคน
4. ขอยกเลิกใบเสร็จที่ออกในข้อ 2 (admin ช่วยอนุมัติ)
5. ตอบคำถาม: ลืมบัตรทำอย่างไร · เช็คชื่อผิดคนทำอย่างไร · สลิปไม่ชัดทำอย่างไร
