# MVP1: ขั้นตอนทดสอบและสคริปต์เดโม

เอกสารนี้ใช้ทั้งทดสอบก่อนส่งงานและเดโมให้ลูกค้า ทำตามลำดับ 1 → 9 ใช้เวลาประมาณ 20 นาที

## เตรียมข้อมูล

| ที่ไหน | ทำอย่างไร | ได้อะไร |
|---|---|---|
| เครื่อง local | `pnpm db:reset` (รัน `supabase/seed.sql`) แล้ว `pnpm dev` | สาขา BKK, คลาส จ./พ./ศ. 17:00 และ ส. 10:00, ผู้ใช้ทดสอบ `admin` `manager` `teacher` `parent` `kiosk` `@demo.test` (รหัสผ่านอยู่หัวไฟล์ seed), นักเรียน S00001, พร้อมเพย์เดโม `0000000000` |
| Cloud (Vercel + Supabase) | ทุกคนล็อกอิน Google 1 ครั้ง แล้วรัน `packages/db/supabase/demo/cloud_demo.sql` ใน SQL Editor (ดู `packages/db/README.md`) | สาขา BKK, คลาส 4 สัปดาห์, role, นักเรียนตัวอย่าง ภูมิ (8 ครั้ง) ข้าวหอม (ไม่จำกัด) และใบสมัคร ใบเตย ที่รออนุมัติ |

ใช้ 3 หน้าต่าง: admin/ครู บนคอม, ผู้ปกครองบนมือถือ (หรือโหมดมือถือ), kiosk บน iPad (หรือหน้าต่างที่สาม)
ห้ามโอนเงินจริงเข้าเลขพร้อมเพย์เดโม ใช้รูปภาพใดก็ได้แทนสลิป

## ขั้นตอน

| # | ใคร | ทำอะไร | ต้องเห็น |
|---|---|---|---|
| 1 | ทุก role | ล็อกอิน | แต่ละ role เข้าหน้าของตัวเอง: admin → หน้าผู้ดูแล, ครู → หน้าครู, ผู้ปกครอง → ข้อมูลนักเรียน, kiosk → เช็คชื่อ |
| 2 | admin | สาขา → แก้ไข BKK: เปิด VAT 7% รวมในราคา, ใส่พร้อมเพย์และบัญชีธนาคาร · ตารางเรียน → สร้างคลาส 4 สัปดาห์ · แพ็กเกจ → ดูราคา | บันทึกแล้ว · จำนวนคลาสที่สร้าง |
| 3 | admin | ผู้ใช้ → แก้ไขสิทธิ์ตัวเอง | เลือก role ไม่ได้ มีข้อความ "เปลี่ยนสิทธิ์ของตัวเองไม่ได้" |
| 3.1 | admin | ผู้ใช้ → แก้ไขสิทธิ์ครู แล้วสลับ role เป็นผู้ปกครองดู (ไม่ต้องบันทึก) | ช่องเลือกสาขาแสดงเฉพาะครู ผู้จัดการสาขา เครื่องเช็คชื่อ |
| 4 | ผู้ปกครอง | ข้อมูลนักเรียน → **ลงทะเบียนนักเรียนใหม่** กรอกชื่อไทย/อังกฤษ วันเกิด ผู้ปกครอง เบอร์ แนบรูปถ่าย ติ๊ก PDPA แล้วส่ง | กลับมาที่ข้อมูลนักเรียนเห็น "ใบสมัครที่รอครูตรวจ" |
| 5 | ครู | ใบสมัคร → เปิดใบสมัคร → อนุมัติ | เห็นรูปถ่ายในใบสมัคร · ได้รหัสนักเรียน S0000x · โปรไฟล์นักเรียนมีรูป |
| 6 | ผู้ปกครอง | การ์ดนักเรียนใหม่ → **ซื้อแพ็กเกจ / ต่อสมาชิก** เลือก 8 ครั้ง (ค่าสมาชิกถูกบังคับเพราะยังไม่มี) → สแกน QR พร้อมเพย์ (ยอดตรงกับยอดรวม) → แนบสลิป → ส่ง | การ์ดขึ้น "ส่งสลิปแล้ว ยอด 3,500.00 บาท รอครูตรวจ" · กดซื้อซ้ำได้หน้า "มีรายการรอตรวจ" |
| 7 | ครู | **ตรวจการชำระเงิน** → ดูสลิป → ยืนยันรับเงิน | ได้เลขใบเสร็จ RC-BKK-ปี-xxxxx เปิดใบเสร็จเห็น VAT 7% · "รับเงินวันนี้" รวมยอดตามวิธีจ่าย |
| 7.1 | ครู | ทำข้อ 6 อีกครั้งกับนักเรียนอื่น แล้วกดปฏิเสธพร้อมเหตุผล | ผู้ปกครองเห็น "สลิปไม่ผ่านการตรวจ: <เหตุผล>" · ไม่มีใบเสร็จ |
| 8 | ครู | นักเรียน → เปิดนักเรียน → จองคลาส 2 วัน · ขายแพ็กเกจเงินสดหน้าร้าน (ทางเดิม) | จองแล้ว · ใบเสร็จเลขถัดไป |
| 9 | kiosk | เลือกคลาสวันนี้ → พิมพ์/สแกนรหัสนักเรียน | ชื่อนักเรียนและครั้งที่เหลือลดลง 1 · สแกนซ้ำขึ้นว่าเช็คชื่อแล้ว |
| 10 | ผู้ปกครอง | ข้อมูลนักเรียน → กด **ดูรายละเอียด** | สรุป: สมาชิกถึงวันที่ · ครั้งที่เหลือ · คลาสถัดไป · รายละเอียด: แพ็กเกจ คลาสที่จอง การมาเรียน |

## เช็กก่อนส่งงาน

- `DATABASE_URL="postgresql:///postgres?host=/tmp" pnpm db:test` ผ่านทุกข้อ
- `pnpm --filter @registerweb/web typecheck`, `lint`, `build` ผ่าน
- ขั้นตอน 1–10 ผ่านบนคอมและมือถือ ไม่มี error ใน console
- ทุกข้อความบนหน้าจอเป็นภาษาไทย
